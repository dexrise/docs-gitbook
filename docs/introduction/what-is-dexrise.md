# What is DEXRise?

DEXRise is a decentralized exchange (DEX) platform for trading digital currencies, designed to serve two audiences at once:

* **Traders** get a simple, well-designed interface to trade on liquidity pools from leading decentralized exchanges — including PancakeSwap, Uniswap and SushiSwap — with rich pair-level detail and a set of protective trading features such as [Slippage Protection](../trading/slippage-protection.md) and the exclusive [Floor Price Protection](../trading/floor-price-protection.md) mechanism.
* **Projects** get production-ready, on-chain services to grow their communities and raise capital: [trading pair listings](../listing/trading-listing.md), [staking pools](../staking/overview.md), [presale events](../presale/overview.md) and [airdrop campaigns](../airdrop/overview.md).

On top of its aggregated trading infrastructure, DEXRise operates [its own liquidity pools](how-it-works.md#native-and-shared-liquidity), which other platforms can use to share liquidity.

## The four core services

| Service | What it offers |
| --- | --- |
| [Trading](../trading/overview.md) | Traditional swap pairs — plus pairs protected by the exclusive Floor Price Protection mechanism |
| [Staking](../staking/overview.md) | Flexible and Locked staking for any two currencies, executed entirely on-chain |
| [Presale](../presale/overview.md) | On-chain token sale events that help emerging projects raise funding and initial liquidity |
| [Airdrop](../airdrop/overview.md) | On-chain reward distribution events for project communities |

## Platform at a glance

| | |
| --- | --- |
| **Platform type** | Decentralized exchange (DEX) with multi-platform liquidity access |
| **Native token** | [DXR](../dxr-token/overview.md) on Binance Smart Chain (BSC) |
| **Signature feature** | [Floor Price Protection](../trading/floor-price-protection.md) — an unbreakable, automatically rising price floor |
| **Execution model** | Staking, claiming and presale purchases settle directly on-chain, with full transparency |
| **Services for projects** | Trading pair listing, staking pools, presale events and airdrop campaigns |
