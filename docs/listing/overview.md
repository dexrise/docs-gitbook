# Listing Fees & Requirements

This section is for **project teams and developers** who want to launch their services on DEXRise. It consolidates everything you need in one place: the **listing fees**, the **requirements**, and the **application process** for all four services.

{% hint style="info" %}
Listing fees and requirements are **separate from user-facing fees**. For example, the [trading fees](../trading/trading-fees.md) that users pay when swapping are unrelated to the pair listing fees on this page.
{% endhint %}

## Listing fee schedule

| Service | Listing fee | Additional fees |
| --- | --- | --- |
| **Trading pair** — traditional listing | $100 | — |
| **Trading pair** — zero-liquidity listing (with Floor Price Protection support) | $3,000 | — |
| **Staking pool** | $50 | — |
| **Presale event** | $50 | 1% of the tokens sold |
| **Airdrop event** | $20 | **Free on Binance Smart Chain (BSC)** |

Each service has its own page with the full requirements:

| Service | Page |
| --- | --- |
| List a trading pair (two listing models) | [Trading Pair Listing](trading-listing.md) |
| List a staking pool | [Staking Pool Listing](staking-listing.md) |
| Launch a presale | [Presale Listing](presale-listing.md) |
| Run an airdrop | [Airdrop Listing](airdrop-listing.md) |

## Shared requirements across services

| Requirement | Details |
| --- | --- |
| **Application form** | Every listing starts with the listing request form: **[Listing Application Form](https://forms.gle/V89E1Nd4eq4N2wtZA)** |
| **Token provision** | The project provides its tokens for the service it is listing — liquidity for trading pairs, the reward pool for staking, the sale quantity for presales, the event quantity for airdrops |
| **Standard tokens** | [Staking](staking-listing.md) and [presale](presale-listing.md) listings support **standard tokens only** — Fee-on-Transfer tokens and similar mechanics are not supported |
| **Decimals limit** | Trading pair listings do not support any token with **more than 18 decimals** |

## How to apply

1. **Review the requirements** for the service you want to list ([trading](trading-listing.md) / [staking](staking-listing.md) / [presale](presale-listing.md) / [airdrop](airdrop-listing.md)).
2. **Prepare your tokens** — the quantity your service requires, per the requirements on its page.
3. **Submit the [listing application form](https://forms.gle/V89E1Nd4eq4N2wtZA)**.
4. If you need help or have questions before applying, reach out through the [official DEXRise channels](../contact.md).
