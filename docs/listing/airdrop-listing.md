# Airdrop Listing

Listing an airdrop on DEXRise lets your project reward its followers and community on-chain — through a one-click [Claim Panel](../airdrop/overview.md) that delivers rewards to every eligible user with a single action.

## Listing fee

| Network | Fee |
| --- | --- |
| **Binance Smart Chain (BSC)** | **Free** |
| **Other networks** | **$20** |

Airdrop listing on **BSC costs nothing** — it is the only DEXRise service with a free listing tier, making it the easiest entry point for any project on the platform.

## Listing requirements

| Requirement | Details |
| --- | --- |
| **Application form** | Submit the [listing application form](https://forms.gle/V89E1Nd4eq4N2wtZA) |
| **Token provision** | Provide the **quantity dedicated to the full airdrop event period** — enough to cover every distribution round of the event |

## What your airdrop runs on

Your event runs on DEXRise's airdrop infrastructure:

* **Multiple distribution rounds within a single event period** — for example, a month-long event that grants rewards daily, instead of one bulk payout. See [Airdrop on DEXRise](../airdrop/overview.md#multiple-distributions-in-one-event).
* A simple **Claim Panel** — eligible users claim with one click.
* All claims execute **directly on-chain**, with transparency and security.

{% hint style="info" %}
Make sure the quantity you provide covers the **entire event period** — including every distribution round if you plan to run multiple rounds within the same event.
{% endhint %}
