# Trading Pair Listing

DEXRise offers **two distinct models** for listing a trading pair. The difference between them is how liquidity is structured — and it is what allows projects at very different stages to launch a market for their token on the platform.

## The two listing models

| | **Model 1 — Traditional listing** | **Model 2 — Zero-liquidity listing** |
| --- | --- | --- |
| **Liquidity structure** | Full 1:1 liquidity — real liquidity in **both** currencies | 1:0 structure — project token liquidity only |
| **USDT side** | Real liquidity held in both currencies (e.g. DXR/USDT) | **Virtual USDT liquidity of up to $1,000,000** — no real USDT required at all |
| **Floor Price Protection** | Not included | **Supported** — the pair can launch with DEXRise's exclusive FPP mechanism |
| **Listing fee** | **$100** | **$3,000** |

## Model 1 — Traditional listing ($100)

The standard listing model, identical in structure to the pairs found on any decentralized exchange: the project provides **real, full liquidity on both sides of the pair at a 1:1 ratio** — for example, a DXR/USDT-style pair backed by genuine liquidity in each currency.

* **Listing fee: $100**
* Suited for projects that hold or can raise real liquidity in both currencies.

## Model 2 — Zero-liquidity listing ($3,000)

DEXRise's alternative model for projects that do not want to (or cannot) supply a full USDT side:

* The project provides **liquidity in its own token only** — the USDT side is handled by the platform.
* DEXRise adds **virtual USDT liquidity of up to $1,000,000** against the pair — **without any real USDT being required at all**.
* The pair **supports Floor Price Protection**, so the project's token can launch with an unbreakable, rising price floor from day one. See [Floor Price Protection](../trading/floor-price-protection.md) for how the mechanism works.

* **Listing fee: $3,000**

## Listing requirements

| Requirement | Details |
| --- | --- |
| **Application form** | Submit the [listing application form](https://forms.gle/V89E1Nd4eq4N2wtZA) |
| **Liquidity provision** | Provide **at least 5% of the token's total supply** to the liquidity pool |
| **Token standard** | No token with **more than 18 decimals** is supported |
| **Fees** | $100 (traditional) or $3,000 (zero-liquidity), per the model chosen |

{% hint style="info" %}
The zero-liquidity model is the only listing model that bundles **Floor Price Protection** — if a protected, upward-structured market for your token is the goal, Model 2 is the one to choose.
{% endhint %}
