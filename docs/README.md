# Welcome to DEXRise Documentation

DEXRise is a decentralized trading platform that combines access to the liquidity of leading decentralized exchanges with a suite of fully on-chain services for traders and crypto projects alike — [Trading](trading/overview.md), [Staking](staking/overview.md), [Presale](presale/overview.md), and [Airdrop](airdrop/overview.md) — all built around its native token, [DXR](dxr-token/overview.md).

Whether you are here to trade, stake, join a presale, claim an airdrop, or launch your own project on DEXRise, this documentation walks you through everything you need to know.
