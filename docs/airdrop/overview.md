# Airdrop on DEXRise

The Airdrop service lets projects run reward distribution events on DEXRise — distributing gifts to their followers or their project community, directly on-chain. It is the simplest of the four DEXRise services to participate in: if you are eligible, one click delivers your reward.

## How airdrops work

| Aspect | Details |
| --- | --- |
| **Purpose** | Distribute rewards to a project's followers and community |
| **Claiming** | Through a simple, one-click **Claim Panel** — eligible users receive their rewards with a single action |
| **Eligibility** | Defined by the project running the event; only eligible users can claim |
| **Execution** | All claims settle **directly on-chain**, with transparency and security |
| **Event structure** | A single event period can contain **multiple distribution rounds** |

## Multiple distributions in one event

An airdrop event does not have to be a single moment of distribution. **The same event period can include more than one distribution round.**

For example: an event that runs for **one month** can grant rewards to the winners **every day** — a daily reward cycle inside a single airdrop event, rather than one bulk payout at the end.

This makes airdrops suitable for sustained community campaigns as well as one-off giveaways.

## Participating in an airdrop

1. Follow the project's official announcement to learn the event period and eligibility rules.
2. Open the event's Claim Panel on DEXRise during the event.
3. If you are eligible, claim your reward — one click, settled on-chain.
